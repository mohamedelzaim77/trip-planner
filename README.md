# Trip Planner Application

This is a comprehensive project for a trip planner application with a React web frontend, a Python Django backend, and a React Native mobile app.

## Setup Instructions
### Backend (Python Django)
1. Navigate to the `backend` directory.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Django server:
   ```bash
   python manage.py runserver
   ```

### Web Frontend (React)
1. Navigate to the `web` directory.
2. Install the required dependencies:
   ```bash
   npm install
   ```
3. Start the React app:
   ```bash
   npm start
   ```

### Mobile App (React Native)
1. Navigate to the `mobile` directory.
2. Install the required dependencies:
   ```bash
   npm install
   ```
3. Start the React Native app:
   ```bash
   npm start
   ```

## Directory Structure:

- **backend**: Contains the Django backend code.
- **web**: Contains the React web frontend code.
- **mobile**: Contains the React Native mobile app code.
